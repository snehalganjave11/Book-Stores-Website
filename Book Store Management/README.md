# 📚 Book Store Website

A simple and responsive **Book Store Website** created using **HTML5 and CSS3**. This project provides a clean and beginner-friendly interface for browsing featured books.

## ✨ Features

* 🏠 Home section
* 📚 Featured Books section
* 🛒 Add to Cart buttons
* ℹ️ About Us section
* 📞 Contact section
* 📱 Responsive design
* 🎨 Simple and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📖 Featured Books

* Atomic Habits — ₹499
* Deep Work — ₹599
* The Psychology of Money — ₹450
* Rich Dad Poor Dad — ₹399

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
